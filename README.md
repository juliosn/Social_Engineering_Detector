# IBM AI Fundamentals' Project: Social Engineering Detector

## About

<p align="justify">This project aims to identify psychological manipulation attempts in written messages, known as <strong>social engineering</strong>. To achieve this, we used simulated phrases and real email excerpts from the <em>Enron Dataset</em> as training examples. Using <strong>Natural Language Processing (NLP)</strong> techniques, we cleaned and organized the data to train a model capable of detecting suspicious content.</p>

<p align="justify">Social engineering is a technique used to manipulate individuals into revealing confidential information. Instead of exploiting technical vulnerabilities, this method relies on exploiting human behavior and trust. It is often used in phishing attacks, scams, and other forms of deception that can compromise personal or organizational security.</p>

<p align="justify">The solution developed in this project can be used as a supporting tool for detecting potential fraud, scams, or phishing attempts, with practical applications in corporate environments and awareness training.</p>
